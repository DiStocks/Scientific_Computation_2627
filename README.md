# # Course Description
Among theory and experiment, numerical methods, data analysis, and visualization have become indispensable tools for science today. This course provides an introduction to the fundamental computational techniques and numerical methods used to model and solve scientific problems. Basic prior programming experience is required.

Note: The image on this page shows how numerical simulations can recreate real-world phenomena, like the fall of a droplet. By the end of this course, you’ll be closer to simulating problems just like this by yourself.

# # Goal of the Course
By the end of the course, you’ll feel confident tackling research projects that involve programming and will be able to write, test, and run your own scientific computing program applied in classic and contemporary computational problems.

In other words, you will be able to write your own code to solve a problem of your interest using one of the numerical methods studying in the course. 

Teaching language
The course will be held in English.

# # Lectures
Each lecture will be built around a Python notebook divided into four parts:

Part A — Theory and Numerical Methods
Introduce the main computational concepts and develop the mathematical foundations of the numerical methods, explaining how they are derived and the ideas behind them.
Part B — Guided Implementation
Use short Python code examples, with explanations, to illustrate the concepts and methods introduced in Part A. Students will then write their own code to implement these methods, building the tools they will need for the exercises and problems that follow.
Part C — Exercises
Work through a variety of exercises, including conceptual questions, partially completed code, and independent programming tasks. These activities will help students consolidate their understanding and gain confidence in implementing and applying the numerical methods.
Part D — Computational Problems
Apply the methods to more challenging problems inspired by computational physics. Students will work in pairs to develop, implement, and analyze their own solutions. The completed work will be submitted as part of the course exercise sheets.

# # Grading 
The assessment for this course will consist of two components:

Computational Exercises
Students will work in pairs to solve and submit one problem for each of the eight Python notebooks covered during the lectures. A selection of problems will be provided, from which each team can choose one.

The submissions will be divided into two deadlines:
First submission — 8 December: One problem for each topic covered up to the mid-semester point.
Second submission — 9 February: One problem for each of the remaining topics covered during the semester.

Oral Presentation and Written Report
Students will also work in pairs to prepare a written report and give an oral presentation on a selected topic or problem. Each presentation will be followed by a short discussion and a question-and-answer session. 

The final grade will be based on the following components:

The average grade of the two computational exercise submissions.
The grade for the written report. The oral presentation is a mandatory requirement for passing the course.
Oral presentations will be given in either English or German.

Note: The format and evaluation criteria for the computational exercises will be discussed during the first lecture.
